## 适用范围

| 场景 | 适用规则 |
|---|---|
| 页面级内容区与导航页签 | 执行页面留白、区块间距及页面级页签规则；不自动套用于弹窗内部页签 |
| 主表、弹窗表格、详情表格、展开子表及流程数据表 | 按各节明确范围执行字号、工具栏、导出、列设置及列宽规则 |
| 分配了可用高度的页面表格卡片 | 执行卡片撑满、分页贴底及表体自适应滚动规则 |
| 弹窗及展开子表 | 根据所在容器与内容布局，不机械套用页面卡片撑满高度；弹窗执行自然高度及内容区限高规则 |
| 滚动条外观 | 依本节明示范围执行，侧边栏、弹窗及抽屉不纳入统一外观调整 |

- 项目规范规定目标要求，具体修改仍受本次任务范围约束；不得以整理规范为由扩大页面整改范围。
- 尺寸、状态、操作顺序及例外以对应章节为准；示例页面名称不构成新增或恢复业务模块的要求。

## 任务分级与执行效率

### 按修改影响选择范围

| 修改类型 | 读取与检查范围 | 验收范围 |
|---|---|---|
| 局部文案、字号、间距、已有组件布局 | 目标组件、对应样式和相关规范小节；涉及共享引用时再展开 | 目标区域及直接关联交互；存在对应导出或详情文案时同步核对 |
| 共享组件、全局样式、主题 | 搜索实际引用并列出影响范围；复杂修改的确认条件遵循项目入口「修改前定位与范围控制」 | 实际受影响的页面、弹窗及抽屉 |
| 库存、状态、导出等业务联动 | 追踪相关数据、状态与操作入口，读取对应业务及交互规范 | 受影响的完整流程、列表与详情同步及数据一致性 |

- 同时涉及多类改动时合并相关检查项；发现共享引用或业务联动后扩大到实际受影响范围，不因局部修改自动检查全站。
- 首次交付、全局导航或框架改动执行完整通用验收；其他修改按影响选择相关通用检查项及专项验收，已确认的设计和业务规则继续适用。

### 集中读取与操作

- 定位目标后，一次批量读取已知相关文件、样式及规范片段；相互独立的检索与读取合并调用，存在依赖的步骤按结果继续。
- 同一会话已读取且未变化的内容直接沿用；新会话读取相关章节，出现新改动、新证据、错误或上下文不确定性时重新定位并补读。
- 默认不读取完整离线 HTML、压缩产物、依赖目录或全仓库 diff；确需排查时，先检索目标，再返回匹配片段或必要摘要。
- 同一请求内集中完成修改后，按「实现与交付」选择预览验证、类型检查或经用户确认后的离线打包；无新增修改、失败或未解决疑点时，不重复相同检查。
- 同一环境已确认阻断的浏览器访问方式，仅在访问条件变化后重试；存在可用替代方式时采用，否则按通用验收要求说明未验收项目；替代方式未覆盖的离线验证仍列为待验收。
- 仅在用户要求分析效率，或出现反复失败、异常缓慢时，读取相关会话日志定位耗时；日常页面修改不默认执行耗时复盘。复盘关注实际执行耗时、模型调用次数及工具输出量，排除用户输入前的等待，不设置固定完成时间或硬性调用上限。

## 规范来源与主题

### 规范来源与组件使用

- 本项目设计要求按以下顺序执行：用户明确要求及已确认设计 → 项目实际安装版本对应的 Ant Design / ProComponents 官方规范 → ant-design-skill 中的规范与模板。
- 官方规范是组件外观、状态、交互和用法的基准；已确认的主题、分页、工具栏及操作区布局属于项目约定，不表述为官方强制要求。
- 设计和实现中后台页面时使用 ant-design-skill，按需读取对应规范和模板；模板中的自定义样式和布局与本项目要求冲突时，调整模板，不覆盖已确认设计。
- 技能入口：/Users/sky/.skills-manager/skills/ant-design-skill/SKILL.md。
- 所有标准界面组件统一使用 Ant Design，业务组合组件按需使用 ProComponents；优先使用原生能力，不手写仿制已有标准组件。
- 官方组件未直接提供的业务能力，使用 Ant Design 组件组合并补充必要交互，保持规范一致；不将拖拽列排序等扩展能力描述为 Table 原生内置功能。
- 组件用法以项目实际安装版本为准；遇到未知能力或版本差异时查阅对应官方文档，不编造组件或属性，不为套用模板自行升级依赖。

### 主题管理

- 保留已确认的主题和布局；未明确指定的组件样式及状态沿用官方默认，不自动采用 skill 中的自定义值。
- 主题色、字号、圆角和组件尺寸等可配置样式优先通过 ConfigProvider（全局配置）和 Design Token（设计变量）集中管理。
- 局部 CSS 仅用于必要布局或官方配置无法满足的已确认需求，限定作用范围；不得通过全局覆盖改变其他页面或组件状态。


#### 验收

- 检查是否实际使用 Ant Design 组件，以及默认、悬停、选中、禁用、校验错误等适用状态和交互是否符合对应版本官方规范及已确认要求。
- 检查主题配置是否集中管理，局部样式是否影响无关页面或组件；检查 skill 模板是否保留项目已确认的主题、布局及交互要求。

## 页面布局与组件尺寸

### 页面一致性

- 同一原型共用导航框架，列表、详情、新增和编辑页保持视觉一致。
- 面包屑已显示当前菜单标题时，所有页面均不在面包屑下方重复显示该菜单标题。
- 所有主页面内容区四周与顶部栏、侧边栏及视口边缘保持 20px 间距，桌面及窄屏均适用；不计入顶部栏、侧边导航、卡片内部间距，也不套用于弹窗和抽屉内部内容。
- 页面容器自身不得重复叠加外层留白；固定定位的页面内容应与共享内容区边界对齐，并为上下间距调整同步保留布局高度，避免遮挡和裁切。
- 列表与管理页面的页面级区块（页签、筛选区、统计区、结果区）之间统一留 16px 间距；此为项目设计约定，不是 Ant Design 官方强制标准。概览看板区块、卡片内部 padding、表格工具栏及弹窗／抽屉内部间距不受本规则影响。
- 展示真实业务语义的模拟内容，避免无意义占位文字。
- 页面文案面向产品使用者，不放技术实现说明。

### 表格与筛选区字号

- 以下为项目字号约定，覆盖主列表、弹窗表格、详情表格及展开子表；紧凑布局不自动缩小字号。

| 内容 | 字号与字重 |
|---|---|
| 表格正文、操作链接、状态文字 | 14px，常规字重 |
| 表头 | 14px，字重 500–600 |
| 筛选标签、输入内容、占位文字、下拉选项及筛选按钮 | 14px |
| 已选数量、分页文字 | 14px |
| 表格及筛选区辅助说明 | 12px |
| 表格区标题 | 18px，字重 600 |

- 优先通过 ConfigProvider 和 Design Token 管理字号；必要局部覆盖限定于业务文字，不以全局替换影响菜单、面包屑、页签、弹窗标题、指标及图表。
- 辅助说明按业务语义识别，不将编号、状态或主要数据因颜色较浅而缩小为辅助字号。
- 字号调整后保留已确认的控件宽度和间距，控件高度执行下文尺寸约定；空间不足时使用换行或横向滚动，不缩小字号强行容纳。


#### 验收

- 按本节字号表检查表格正文、表头、操作、状态、筛选文字、标题及辅助说明；同时检查默认、选中、禁用、占位和下拉展开状态的一致性，并覆盖详情、弹窗和展开子表。

### 页面级页签

- 以下为项目设计约定，不是 Ant Design 官方强制标准；适用于“成品库存／托盘管理／入库记录／出库记录”等页面级导航 Tabs。

| 状态 | 字号 | 字重与样式 |
|---|---:|---|
| 未选中 | 16px | 400，常规文字色 |
| 选中 | 16px | 600，主题蓝色＋底部指示线 |
| 禁用 | 16px | 400，沿用主题禁用色 |

- 切换状态时字号不变，通过颜色、字重和指示线区分。
- 各页面保持一致的页签间距和容器高度，不因选中状态发生布局位移。
- 页面级页签统一置于页面内容顶部的独立栏位，位于筛选区、统计区和结果区之前；栏位横向占满页面内容可用宽度，页签水平排列。
- 页面级页签栏与下方页面区块之间保留 16px 间距，与列表及管理页面的页面级区块间距约定一致。
- 本规则不自动套用于表格结果分类、分段选择器或弹窗内部页签。
- 字号层级统一为：表格区标题 18px → 页面级页签 16px → 表格与筛选 14px → 辅助说明 12px。


#### 验收

- 检查页面级页签栏的位置、可用宽度及与下方区块的间距符合本节规则，且不同页面布局一致。
- 按本节状态表检查页面级页签的字号、字重、颜色及指示线；切换时字号、间距和容器高度稳定，无布局位移。

### 组件尺寸与布局适配

- 以下为项目布局约定，不表述为 Ant Design 官方统一尺寸要求。

| 场景 | 尺寸约定 |
|---|---|
| 常规筛选、普通表单、弹窗及对应操作按钮 | `middle`，32px |
| 常规分页页码、翻页按钮、每页条数选择器及跳页输入 | 32px |
| 明确需要紧凑操作的场景 | `small`，24px |
| 明确需要突出操作的场景 | `large`，40px，按具体需求使用 |

- 默认使用 `componentSize="middle"`；主题集中设置 `controlHeight: 32`、`controlHeightSM: 24`、`controlHeightLG: 40`，常规控件字号保持 14px。
- 同一操作组保持尺寸一致；检查主题、局部覆盖和实际高度，不能仅根据 `size` 名称判断尺寸。
- 表格内置的常规分页显式采用 `size="middle"`，避免跟随小尺寸表格自动缩为紧凑分页；表格本身的 `size` 和行高保持独立。
- 标准高度优先于旧的局部高度配置，不保留筛选区 36px／40px 或分页 40px／42px 的冲突覆盖。
- 宽度按字段内容单独设置；多行文本按内容撑高，表格行高、工具栏容器、导航、页签及头像不按控件高度机械替换。

- 按组件用途、内容长度和操作密度选择合适尺寸；优先使用当前版本支持的 `size` 属性及项目统一 Design Token，不为填满空白或强行塞入一行而单独改变组件高度、字号、内边距或缩放比例。
- 同一场景下的输入框、选择器、日期选择器和按钮保持尺寸协调；不同场景可采用不同尺寸，不要求全部组件使用同一档位。
- 区分组件尺寸档位与布局宽度：`size` 不等于宽度配置；控件宽度应根据字段内容和使用场景单独确定。
- 控件宽度与标签宽度分别计算，标签不压缩；长标签不能挤占控件最低可用空间。
- 筛选控件按典型完整内容选宽，并预留清空、搜索及下拉图标空间；日期范围需完整展示起止日期、分隔符及操作图标，不因筛选项减少而自动拉伸至整行。
- 项目控件宽度参考：短枚举 120–160px、普通选择器 180–220px、长编号及关键词 280–320px、日期范围 280–320px；宽度不包含标签，按实际内容选用，不表述为 Ant Design 官方尺寸。
- 批次号查询输入框统一使用 280px 宽度；窄屏下可受可用容器宽度限制，但不超过容器宽度。
- 宽度配置应作用于组件实际外层，兼顾带清空按钮或搜索图标的 Input 外层容器；局部样式限定于对应业务区域。
- 筛选项较少时允许筛选区保留空白，不以铺满卡片或所有控件等宽作为排版目标。
- 不对所有输入类组件统一设置 `width: 100%` 或 `flex: 1`；单列表单、长文本输入等确需填满字段区域的场景，可以使用，但须先合理限定字段容器宽度。
- 可伸缩控件应按场景设置宽度边界，避免宽屏无限拉长或窄屏压缩到内容不可读；同类场景复用统一宽度规则。
- 空间不足时优先调整栅格、排列方式或筛选区换行；表格工具栏继续遵循单行及“更多”菜单规则，不靠缩小字号、控件或无下限压缩强行容纳。
- 按钮宽度默认随文案和组件标准内边距确定；仅在已确认的整行按钮、等宽按钮组等场景中主动拉伸。
- 表格、卡片等内容容器仍按页面布局分配空间；弹窗尺寸和表格列宽继续执行对应专项规范。


#### 验收

- 检查控件尺寸是否与场景匹配，同类控件是否一致，是否存在为填满空白或强行排入一行而拉伸、压缩或缩放组件的情况。
- 按本节尺寸表及字号约定检查常规筛选、表单、弹窗、对应按钮与分页控件；同组控件垂直对齐，默认、禁用、搜索、清空、日期选择及校验状态无文字或图标裁剪，明确的紧凑操作除外。
- 分别检查少量筛选项、完整长编号及宽窄视口：标签不挤压控件，编号、起止日期、清空／搜索／下拉图标和操作按钮完整可见；空间不足时换行，无重叠、横向溢出或控件过度拉伸造成的大块内部留白。

## 弹窗与表单

### 弹窗尺寸与布局

- 弹窗统一使用 Ant Design Modal，按内容复杂度选择尺寸，不将所有弹窗套用同一个宽度。
- 纯文字二次确认采用 Modal 确认类组件的默认尺寸；少量字段、单列布局的普通弹窗优先采用 Modal 默认宽度 520px，例如仅选择入库仓库的确认弹窗。
- 多字段表单可按需选用 640px / 800px，包含宽表格或复杂详情时可选用 960px；这些是项目选型参考，并非官方强制尺寸，仅在内容确有需要时扩大。
- 高度随内容自然撑开，不为短表单设置固定高度、过大的最小高度或空白占位；优先沿用官方组件内边距，避免重复叠加 padding。
- 弹窗尺寸不得超过可视区域；桌面端左右各至少留出 24px，窄屏可收敛至各 16px，上下保留必要间距，确保标题、关闭按钮及底部操作区完整可见。
- 内容超出可用高度时，限制内容区最大高度并仅在内容区滚动；短内容不强制出现滚动条，不将底部操作区放入内容滚动区。
- 尺寸配置集中管理，按实际场景选择；通过当前版本支持的 width、styles 等官方配置实现，不通过全局样式统一放大弹窗或改变其他组件。

### 表单与弹窗操作区

- 保存、取消、确认等操作按钮使用 Ant Design Button，保留在对应表单或弹窗内容下方已确认的操作区，不改变原有位置、排列顺序及对齐方式。
- 原有固定底部操作区继续保持固定，内容滚动时操作按钮始终可见，并为内容预留空间，避免遮挡。
- 统一组件规范或调整布局时，不将底部操作按钮迁移到顶部、标题栏或其他区域。


#### 验收

- 检查短表单、复杂表单及含表格弹窗的尺寸是否匹配内容；在常用桌面分辨率和窄视口下检查无大块无效留白、越界、双重滚动或按钮遮挡。
- 检查表单与弹窗底部操作按钮的位置、顺序及对齐方式；滚动至内容底部，确认固定操作区可见且不遮挡内容。

## 表格与导出

### 表格标题与操作区

- 表格标题、选中状态、批量操作及常规操作统一放在表头上方的同一行工具栏中。
- 左侧显示标题；选中数据后，在标题旁显示“已选 N 项”和“清空选择”。
- 本节工具栏布局适用于主表、弹窗表格、详情表格、展开子表及操作流程中的数据表；只遵循各表已有的选择能力和操作集合。
- 工具栏左侧显示标题及选中状态；右侧操作区整体靠右，常规操作组（固定操作组）始终靠最右，组内顺序和位置保持稳定。
- 有选中项且该表有批量操作时，批量操作组整体靠右，紧邻常规操作组；两组之间用竖向分隔线区分，批量按钮不得穿插到常规操作组中。
- 批量操作组仅在选中数据后显示；没有选中项或该表没有批量操作时，批量组及组间分隔线均隐藏。不得为原本不支持多选的表格新增选择框或批量操作。
- 批量操作组内既有按钮顺序保持稳定；“批量导出”固定为该组最右侧、紧邻分隔线的按钮，其他批量操作排在其左侧。不得因批量组显隐改变常规操作组的位置。
- 例如：选中后显示“果品资料　已选 N 条　清空 ｜ 批量启用、批量停用、批量删除、批量导出 │ 新建果品、导出、列设置”，具体按钮按页面已有需求提供，不额外新增操作。
- 所有支持多选的业务表格在选中一条或多条记录后，均显示文字按钮“批量导出”；仅导出当前表格已选记录，包含跨页保留的选中项，不包含未选记录。取消或清空选择后隐藏该按钮。
- 存在多种选中记录类型时，按各自数据格式分别导出 CSV，不混用字段格式。
- 工具栏高度保持稳定，不额外生成选中提示行或批量操作行；选中、取消及清空选择时，表头和数据区域不发生上下位移。
- 空间不足时将低频操作收入 Ant Design Dropdown 的“更多”菜单，保持单行，不遮挡标题或其他控件。
- 操作按钮统一使用 Ant Design Button；此处位置固定指布局稳定，不要求随页面滚动吸附。
- 工具栏中的新增、新建、登记及导出操作使用带文字的按钮，不显示操作图标；批量导出同样保留文字。列设置、刷新及密度调整等工具操作使用仅显示图标的按钮，并提供 Tooltip 提示和可访问名称；不因本条规范新增原本不存在的操作。
- 所有业务数据表格的常规操作组按从右向左的顺序固定为：最右侧“列设置”图标按钮，其左侧为文字“导出”按钮，再左侧为页面已有的常用固定业务操作按钮；不因页面或页签切换改变这一相对顺序。支持批量操作的表格在选中后，将批量组放在常规操作组左侧并用竖线分隔。
- 所有业务数据表格默认提供文字“导出”按钮，放在表格标题同行的工具栏常规操作区；主表、弹窗、详情表、展开子表及操作流程中的数据表均适用。导出当前筛选后的全部记录，不受分页影响；支持多选的表格在有选中记录时导出所选记录，否则导出当前筛选结果。无可导出记录时按钮保留并禁用。


#### 验收

- 检查表格标题与操作同行，选中和清空后工具栏高度、常规按钮位置及表格位置保持稳定。
- 检查所有适用表格的工具栏均为左侧标题及选中状态、右侧操作区整体靠右；批量组紧邻常规操作组并以竖线分隔，批量按钮未穿插到常规按钮之间。
- 检查无选中项或无批量操作的表格不显示批量组及分隔线；批量组显隐不改变工具栏高度和表格垂直位置，常规操作组始终靠右且位置稳定。
- 检查所有支持多选的表格在有选中记录时显示“批量导出”，清空选择后隐藏；跨页选中仍保留，导出文件只包含全部已选记录。
- 检查“批量导出”始终是批量操作组最右侧按钮并紧邻组间分隔线；多类型混合选中时分别按各自格式导出，不遗漏或串用字段。
- 检查所有业务数据表格常规操作组从右向左依次为列设置图标、导出、页面已有的常用固定业务操作；页面和页签切换后顺序保持一致。
- 检查工具栏空间不足时“更多”菜单可用，无换行、重叠或遮挡。
- 检查所有业务数据表格均有常驻文字“导出”按钮；筛选结果全量导出不受分页影响，多选时仅导出所选记录，空结果时按钮禁用。

### 表格列设置

- 所有业务数据表格提供“列设置”入口，统一放在与标题同行的工具栏右侧常规操作区；主表、弹窗表格、详情表格及展开子表均遵循此规则。
- 列设置使用 Ant Design 组件组合实现，支持通过 Checkbox 复选框控制业务列的显示与隐藏。
- 列设置面板中的字段选项统一按单列纵向排列，每行显示一个字段；此布局适用于所有业务表格及其页签，不提供双列切换。
- 列设置面板支持通过拖拽手柄调整列顺序，调整结果同步到表格从左到右的显示顺序；此处排序指列位置调整。
- 行选择列、展开控制列和操作列保持固定位置，不参与显隐选择和拖拽排序；至少保留一个业务列显示。
- 提供“恢复默认”，一次恢复该表格初始的列显隐状态和列顺序。
- 列显隐及顺序调整即时生效，各表格配置独立维护；默认在当前会话中保留，刷新后恢复初始设置。
- 调整列配置后，按当前可见列重新计算横向滚动宽度，并保持列宽、固定列及表头与内容对齐。


#### 验收

- 检查各表格列设置的复选显隐、拖拽排序、恢复默认、配置独立性及滚动宽度同步。

### 表格列宽

- 按字段内容和业务重要性设置列宽，避免所有列等宽；数字、时间、长文本和操作列按实际内容安排宽度。
- 操作列仅有一个文字按钮时，按钮在单元格内水平居中；有多个文字按钮时，将按钮作为一组水平居中排列，按钮间距保持一致。操作列宽度按操作数量和文案预留，避免按钮重叠、拥挤或截断。
- 表格总宽度超过容器时启用横向滚动，并使滚动宽度与当前可见列宽总和一致。
- 列显隐、列顺序或条件列变化时，同步检查列宽与横向滚动宽度。
- 长内容无法完整展示时使用省略显示，并沿用现有交互提供查看完整内容的方式。
- 调整后检查主表、弹窗表格、详情表格和展开子表，避免内容截断、重叠或横向溢出。


#### 验收

- 检查各页面表格的列宽、横向滚动及内容遮挡，确认复选框与相邻列无重叠、表头与数据列对齐。
- 数据总数大于零时，必须确认表头、当前页数据行和关键字段实际可见；不能仅凭分页总数或生成的标记判断内容正常。

### 表格滚动与底部分页

- 所有业务页面及页面内表格的横向、纵向滚动条统一参照“采摘称重”页面：使用细滚动条、浅色滑块和透明轨道；内容未超出滚动容器时不显示滚动条或滚动位置。
- 统一滚动条外观时保留各页面现有滚动容器、滚动方向、尺寸和布局，不为显示滚动位置强制制造溢出；此规则不套用于侧边栏、弹窗和抽屉。
- 所有表格分页统一使用 Ant Design 的 Pagination 组件，不自行实现页码按钮、每页条数选择器或跳页输入框。
- 统一参照已确认设计：左侧显示“共 N 项数据”，右侧排列上一页、页码、下一页、每页条数选择器及“跳至”页码输入框。
- 数据总数使用千位分隔符，并随筛选结果更新；默认每页 20 条，选择器显示“20 条/页”。
- 使用 Pagination 内置的页码省略、每页条数切换、快速跳页及首尾页禁用能力。
- 当前页采用主题蓝色背景、白色文字和圆角；通过 Ant Design 主题配置及必要的局部样式统一外观。
- 表格卡片占满页面布局分配的可用高度；不得因当前页数据较少而按内容收缩卡片或包含分页区的父容器。
- 结果卡顶部工具栏（含标题）距卡片上沿保留 16px，由卡片内容区承担；工具栏不得重复添加顶部 margin 或 padding。工具栏与首排卡片之间另保留 16px，两段间距各由对应容器承担，不得相互替代或叠加。
- 分页区在布局上锚定于表格卡片底部，不固定到浏览器视口；采用白色背景和顶部浅色分隔线，左右与表格内容对齐，所有控件垂直居中。
- 表格和卡片列表的外置分页区距结果卡片下沿保留 16px；该间距由分页区容器承担，不依赖其他父容器偶然提供的留白。卡片列表使用 `ds-list-pagination` 或等价的 `padding: var(--padding) 0`，并避免父子容器重复叠加分页区底部间距。
- 分页区独立于表格内容滚动区域；表格纵向或横向滚动时，分页位置保持稳定且不遮挡数据或滚动条。
- 需要内部纵向滚动的长表格，滚动区域按表格卡片可用高度自适应，扣除工具栏、表头和分页区后确定高度；避免设置过小的固定高度上限，造成表格下方与分页分隔线之间的大块空白。
- 表格滚动区下沿或卡片列表末张卡片与分页顶部浅色分隔线之间保留 16px 间距；卡片列表须在可滚动区域底部保留该间距，滚动到底时最后一张卡片也不得贴住分隔线。短表格按行数自然展示，不强制出现纵向滚动条；剩余空间保留在卡片内表格区域，不能使分页上移或在卡片外留下空白。
- 标签管理页的模板卡片列表不显示底部分页器或分页分隔线；全部筛选结果在结果卡片内滚动，列表末尾由卡片网格保留 16px 留白。
- 各页面保持相同的控件高度、字号、圆角和间距；页码及数据总数根据实际模拟数据计算，不写死参考图数值。
- 参考图中的红色框仅为标注，不作为界面样式。


#### 验收

- 对配置分页的列表，分别用少于一页的数据、需要纵向滚动的数据及空结果验收：分页贴在结果卡片底部且顶部有分隔线；短表格不强制出现纵向滚动条，剩余空间留在卡片内；长表格滚动区按可用高度自适应。
- 窗口尺寸变化及表格横向、纵向滚动时，检查分页仍与表格内容滚动区分离、保持卡片底部位置，分隔线可见，内容不被遮挡。
- 检查结果卡顶部工具栏容器距卡片上沿为 16px（标题随工具栏对齐），工具栏与首排卡片另有 16px 间距；调整窗口尺寸后仍稳定，且没有父子容器重复 padding 造成双倍留白。
- 检查标签管理页无底部分页器和分页分隔线；全部筛选结果均可在卡片网格中滚动查看，滚动到底时末张卡片与卡片内容区底部保留 16px 留白。
- 检查表格和卡片列表的分页区与结果卡片下沿保持 16px 间距；卡片列表滚动到底时，末张卡片与分页分隔线之间也保留 16px。调整窗口尺寸或滚动列表内容后，间距仍稳定，分页不贴边、不被裁切，且没有重复 padding 造成双倍留白。
- 检查所有业务页面及页面内表格的横向和纵向滚动条样式一致；可滚动时显示细浅色滑块和透明轨道，不可滚动时不显示滚动条或滚动位置；确认侧边栏、弹窗和抽屉未被本规则改变。

## 成品出库专项

### 成品整托与整箱出库

- 成品出库在同一页面提供“托盘”和“整箱”两种模式；托盘模式扫码仅接受托盘码，整箱模式扫码仅接受箱码，码型不匹配时提示切换到对应模式。
- 托盘码和箱码分别进入托盘待出库清单、整箱待出库清单；两个清单独立维护。切换模式只切换当前查看和操作的清单，不合并或清空另一清单。
- 选中候选托盘汇总行后加入托盘清单，选中托盘展开区的箱明细后加入整箱清单；同一箱不得同时进入两类清单。
- 每种模式单独确认当前清单；只有确认成功后才扣减该清单对应的库存。确认一种模式不清除另一模式的待出库记录。
- 候选表混合选中托盘汇总和箱明细时，批量导出按托盘汇总、箱明细各自格式分别生成 CSV；整箱候选表只导出箱明细格式。
- 切换出库仓库时清空两类待出库清单，避免将不同仓库的货物合并出库。


#### 验收

- 检查成品出库托盘与整箱模式的扫码校验、独立待出库清单和独立确认；切换模式不合并或清空另一清单，确认后仅扣减当前清单库存。
- 检查托盘候选汇总与展开箱明细混合选择后分别生成对应 CSV，整箱候选表导出箱明细格式；切换仓库后两类待出库清单均清空。

## 布局诊断与回归处理

- 修改组件内部布局前，核对实际安装版本和实际渲染的 DOM（页面元素结构）；选择器、内联样式及滚动行为须有依据，不沿用其他版本的内部类名，不将某一版本的内部类名作为永久实现约定。
- 高度或滚动异常须逐层检查卡片、内容容器、组件外壳、表头、滚动区和分页区，确认可用高度传递、Flex（弹性布局）父子关系、溢出裁剪及样式优先级后再修改。
- 不为试修向整组嵌套容器批量设置 `height: 0`、固定高度或 `overflow: hidden`；确有需要使用这些设置或 `!important` 时，须说明作用、覆盖对象及优先级，并检查表头、数据行和滚动区域没有被压缩或裁剪。
- 列干涉须先确认列宽、单元格内边距、固定列偏移、滚动位置及表头与数据对齐情况；证据不足时不得直接断定为列宽不足。
- 用户反馈修复无效或出现回归时，先撤销引入回归的具体改动，保留其他已确认修改，重新核对根因，再做最小范围修复。


#### 验收

- 共享样式修改后，检查所有受影响的主列表；按选择器作用范围检查弹窗表格及详情表格。

## 实现、离线交付与通用验收

### 实现与交付

- 已有项目复用现有工程；新项目只建立运行和打包所需的最小结构。
- 复用现有工程技术栈，按需适配 ant-design-skill 模板，源代码按页面和组件拆分；不为套用模板自行迁移技术栈。
- 不为原型引入无必要的服务层、权限框架、状态管理库或部署体系。
- 预览、类型检查及打包的触发条件统一遵循 [项目入口的执行表](../AGENTS.md#实现验证与交付)；仅修改规则文档时不启动预览、不做类型检查、不构建。
- 日常页面修改通过 `pnpm dev` 本地预览，使用 HMR（热更新）查看最新效果；优先复用本项目已有开发服务，未运行时再启动并提供实际预览地址。
- 用户明确要求打包（如“确认，打包”）或导出离线文件后，将全部页面打包成一个可离线打开的 HTML 文件。
- 必要脚本、样式、图标和图片内嵌；字体优先使用系统字体。
- 最终文件不依赖 CDN、在线接口、本地服务器或外置资源文件。
- 多页面采用 Hash 路由，支持本地打开及浏览器前进、后退。
- 保留开发源文件，最终 HTML 放入项目的 delivery/ 目录。
- 局部文案、局部样式调整仅验证目标区域和直接关联项，不运行完整构建；涉及共享组件、全局样式或主题时，按实际引用范围验证受影响场景，涉及逻辑、类型或组件接口时执行类型检查。
- 类型检查失败时修复后重跑。
- 确认前不更新 `delivery/index.html`；有尚未打包的展示、交互或资源修改时，说明本地预览为最新版本、离线 HTML 仍为上次打包版本。
- 用户确认打包后，统一执行一次 `pnpm build`；当前命令为 `tsc --noEmit && vite build`，已含类型检查，本轮直接打包时不再预先单独执行相同类型检查；命令配置变化时以 `package.json` 为准。
- 打包失败时修复后重跑；离线验收发现的问题在本轮交付内修复后重新打包，确保最终文件与交付源码一致。交付完成后的新一轮修改回到本地预览流程，等待用户再次确认打包。
- 未发生变化且没有新增失败或未解决疑点时，不重复构建与已通过的检查。
- 仅在用户要求时提供在线部署。

### 通用验收

- 以下为通用检查项：首次交付、全局导航或框架改动完整执行；其他修改按「任务分级与执行效率」选取受影响项，并执行相关专项验收。
- 日常修改在本地开发预览中验证；确认打包后直接打开最终 HTML，在断网条件下验证相关显示和交互。
- 检查菜单、页面跳转、返回、筛选及主要新增和编辑流程。
- 检查相关页面的数据同步、表单校验和空结果状态。
